# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub security advisories. Do not open
a public issue, discussion or pull request.

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, the affected crate or workflow, the commit or version, and the steps to
   reproduce it.

If the **Report a vulnerability** button is not shown, private reporting is not enabled for the
repository yet. In that case, open a public issue titled "Security contact request" that contains
no details of the problem. A maintainer will reply with a private channel for the report.

GitHub's guide to the private reporting flow is
[Privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

The maintainers will acknowledge the report, work on a fix in a private advisory, and credit you
in the published advisory unless you ask otherwise.

## Supported versions

hostkeeper is pre-release and has no release yet. Fixes land on the `main` branch.
